# 02_requirements

## 機能要件

### 長文一覧表示

- 収録済み長文の一覧を表示できる
- タイトル、語数、レベル目安、タグを確認できる
- 一覧から詳細画面へ遷移できる

### 長文詳細表示

- 1件の長文を読みやすく表示できる
- タイトル、出典、本文、語数を確認できる
- 既読状態や保存単語操作へつながる
- センテンスごとに日本語訳を確認できる
- 日本語訳は初期表示では折りたたみ、必要な時だけ開ける

### 単語保存

- 読書中に単語を保存できる
- 保存時は原形、本文内での品詞、本文内の日本語意味、保存元 passage、保存日時を記録する
- 単語帳では、その単語が持つ品詞と日本語意味を一覧で扱えるようにする（本文内の品詞・意味を含む）

### 熟語保存

- 教材データに登録された熟語を本文上で判別できる
- 熟語に含まれる単語は初期表示では常時ハイライトしない
- 熟語に含まれる単語へカーソルを合わせた時だけ、熟語構成語をハイライトできる
- 熟語ヒントのポップアップには熟語テキストを表示する
- 熟語ヒントのポップアップには意味を表示しない
- スマホでは対象語をホールドした時に熟語ヒントを表示できる
- ポップアップ内の熟語は複数選択できる
- 熟語を選択した状態で `save` を実行すると、選択中の熟語をイディオムとして tray に保存できる
- 熟語は単語と区別して保存できる

### 単語一覧表示

- 保存済み単語を一覧表示できる
- 元の passage を辿れる
- 削除できる
- ユーザーが作成したフォルダへ整理できる
- 1つの単語は複数フォルダに所属できる
- 単語帳の品詞は日本語で表示する
- 英文例は表示/非表示を切り替えられ、日本語訳も併記できる
- 単語カードの「品詞と意味」「フォルダ」「英文例と日本語訳」は初期表示で展開状態にする

### 単語保存 tray

- 読書中に保存候補を一時 tray へ入れられる
- tray 内の語句は個別削除できる
- tray 内の語句はまとめて全削除できる
- tray から単語帳へ一括保存できる
- 複数語句を選択している場合、`save` を実行したら選択状態を自動解除する

### reader 語句操作モード

- reader 画面で語句操作モードを切り替えられる
- モード切替 UI は本文センテンス一覧の直前（センテンスのすぐ上）に配置する
- `文型選択のみ`: 文型ラベル（`S`, `V`, `O`, `C`, `M`）と `clear` のみ使える
- `tray追加のみ`: `save` のみ使える
- `両方`: 文型ラベル、`clear`、`save` の全操作を使える
- `閲覧のみ`: 語句操作を行わず、本文閲覧のみ行う
- 複数語句を選択している場合、文型ラベル選択または `clear` 実行時も選択状態を自動解除する

### 既読管理

- 長文ごとの既読状態を保持できる
- 一覧で既読判別できる

### ローカル保存

- 学習状態をブラウザ内に保存できる
- 再読込後も状態を復元できる

### 暗記シート

- 保存単語全体または任意のフォルダを暗記シートとして使える
- 英単語を隠す表示と、日本語意味を隠す表示を切り替えられる
- 各カードはクリックまたはタップで隠した情報を表示できる
- カードには操作説明を表示し、表示後は「タップして隠す」を示す
- 意味の表示では本文内の意味だけでなく、品詞ごとの意味も表示できる
- 複数品詞がある場合、品詞ごとの意味はすべて表示できる
- 品詞表示は日本語で表示する
- カード上部に品詞ラベル（例: `ARTICLE`）は表示しない
- 「タップして表示」の案内は1つだけ表示する
- カードを表示した時は、英語例文の下に日本語訳も表示できる
- 例文日本語訳が未登録の場合は表示しなくてよい
- カード表示時は、例文の英語を表示する
- 品詞ごとの意味はカード表示時に確認できる
- `英単語を隠す` モードでは、英単語を黒塗りマスクで隠して表示する
- `英単語を隠す` モードの非表示時は、タップ操作で英単語を表示できる
- 暗記シートの例文欄は英語例文と日本語訳を併記できる
- `英単語を隠す` モードでは、英単語を隠している間も品詞別の日本語意味を表示する
- 本文中で使われた品詞が分かる場合は、その品詞を一覧の先頭に表示する
- 旧来の復習履歴中心の UI は使わない

### フラッシュカード

- 復習画面から `フラッシュカード` ページへ遷移できる
- 保存単語全体または任意のフォルダを対象にフラッシュカード化できる
- カード表示順をランダムに並び替えられる
- 初期表示面を `英単語を先に表示` と `日本語意味を先に表示` から選べる
- 対象と同様に、初期表示と並び順も選択UIで切り替えられる
- 設定項目のすぐ下に大きな1枚表示の学習ステージを表示する
- フラッシュカードは、単語帳アプリに近い素早い表裏確認の操作感を参考にしつつ、配色・配置・文言・導線は本 repo 独自のUIとして設計する
- 既存アプリの画面構成、アイコン配置、文言、カード装飾をそのまま再現しない
- 通常表示では大きな1枚表示で `前へ` / `次へ` によって進められる
- 大きな1枚表示の下に横方向一列のカード一覧を置き、任意のカードへ直接移動できる
- 大きい画面では1枚ずつ進める集中モードを主要操作として使える
- 各カードはタップで表裏を切り替えられる
- 品詞と意味が複数ある場合は縦並びで表示する
- 集中モードボタンで大型ポップアップ表示へ切り替えられる
- 大型ポップアップではカードを1枚ずつ表示し、現在位置、表裏状態、英語例文、日本語訳を確認できる
- 大型ポップアップでは `前へ` / `次へ` で前後に移動できる
- 大型ポップアップではキーボードの左右キーで前後移動、Space / Enter で表裏切替ができる
- `集中モードを終了` ボタンは `前へ` / `次へ` の下に配置する

## 非機能要件

- 軽量
  - 静的Webで動作し、外部依存を最小化する
- API依存最小
  - 初期段階では外部API停止や料金変更の影響を受けにくくする
- 再開容易
  - repo 内文書を読めば会話履歴なしでも続行できる
- スマホ操作性
  - 縦持ち前提で無理なく読めるUIにする
- ライセンス追跡可能
  - 素材ごとに出典と利用条件を追えるようにする

## 初期スコープ外

- 認証
- 課金
- クラウド同期
- 外部生成API前提機能
- 高度な推薦機能
- 学習分析ダッシュボード
