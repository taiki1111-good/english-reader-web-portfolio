# 05_ui_flow_spec

## 対象画面

- `index.html`
- `reader.html`
- `vocab.html`
- `review.html`
- `flashcard.html`

## index.html

### 役割

- 長文一覧の入口画面

### 主要UI要素

- ページタイトル
- グローバルナビ（教材 / 単語帳 / 復習）は、スマホ幅でも横並びを維持する
- 長文カード一覧
- タイトル、語数、レベル目安、タグ、既読表示
- 難易度、タグ、語数、既読状態のフィルター
- `reader.html` への遷移リンク

### 画面遷移

- 一覧選択で `reader.html?id={passage_id}` へ遷移
- 単語一覧への導線を上部または下部に置く

### ボタン押下時の挙動

- 長文カード押下: 対象 passage を開く
- 既読切替ボタン押下: 対象 passage の既読状態を保存または解除し、一覧と学習状況を更新する
- 既読状態フィルター変更: すべて、既読済み、未読のいずれかに教材一覧を絞り込む
- 単語一覧ボタン押下: `vocab.html` へ遷移
- 復習導線押下: `review.html` へ遷移

### スマホ表示優先事項

- グローバルナビは3項目を横に並べ、各項目が必要以上に全幅化しないようにする
- 片手操作でカードを押しやすくする
- 語数やタグは折り返しても読めるようにする

### 教材一覧の空表示

- フィルタ条件に合う教材がない場合は、教材データが未登録に見えないように「フィルタ条件に合う教材がありません」と表示する
- 空表示には条件をリセットする操作を用意する
- JSON 読み込みに失敗した場合は、ローカルファイル直開きではなく静的サーバー経由で開く必要があることを案内する

### 将来の拡張: CEFR・語数説明の追加（Phase 1.5 推奨）

**目的**: ユーザーが「CEFR B1」「148語」の意味を直感的に理解できるようにする

**実装案**:

1. **カード内にツールチップまたはアイコンヘルプを配置**:
   - 「CEFR B1」の横に小さな「?」アイコン
   - マウスホバー時に説明ポップアップ表示
   - 例: "CEFR: ヨーロッパ言語共通参照枠。B1は中級レベル"

2. **ページ上部に簡潔な説明欄を追加**:
   - 「このサイトについて」または「用語解説」セクション
   - CEFR レベル表（A1-C2）と難度目安を記載
   - 語数の意味（教材全体の単語総数）を説明

3. **ポップオーバーまたモーダル**:
   - 初回訪問ユーザー向けの軽いチュートリアル
   - 以降非表示にするチェックボックス付き

## reader.html

### 役割

- 1件の長文を読む主画面

### 主要UI要素

- タイトル
- 出典表示
- 本文
- センテンスごとの折りたたみ式日本語訳
- 既読切替または読了操作
- 語句操作モード切替（文型選択のみ / tray追加のみ / 両方 / 閲覧のみ）
  - 本文センテンス一覧の直前（センテンスのすぐ上）に配置する
- 操作表示モード切替（ポップアップ / 下部固定）
  - 語句操作モードの下に配置する
  - 端末自動判定に頼らず、ユーザーが操作UIを選べるようにする
- 本文上の語句操作ポップアップ
- 熟語ヒント
- 単語帳保存前の一時 tray
- 一覧へ戻る導線
- 本文表示は背景色付きカードにせず、ページ背景になじませる
- センテンス単位の背景色は表示しない

### 画面遷移

- 戻る操作で `index.html`
- 単語一覧ボタンで `vocab.html`
- 復習導線で `review.html`

### ボタン押下時の挙動

- 既読ボタン: 既読状態を保存する
- 採点ボタン（`選択済みだけ採点`）: 文型ラベル回答が入っている語句だけを採点する
- 採点ボタン（`全体を採点`）: 教材の採点対象語句全体を採点する（未回答含む）
- ポップアップモードで本文中の語句にカーソルを合わせる: SVOC/M 選択、clear、save を持つポップアップを表示する
- 熟語に含まれる語句へカーソルを合わせる: ポップアップ内に熟語ヒント（熟語テキスト）を表示する
- ポップアップモードで本文中の語句をクリックする: 語句を一時選択し、複数語句を選択できる
- ポップアップモードで選択中の語句がある場合、SVOC/M、clear、save は選択中の語句全体へ適用する
- ポップアップモードで選択中の語句がない場合、SVOC/M、clear、save はポップアップ対象の語句へ適用する
- 語句操作モード切替:
  - `文型選択のみ`: SVOC/M と clear だけ実行できる
  - `tray追加のみ`: save だけ実行できる
  - `両方`: SVOC/M、clear、save を実行できる
  - `閲覧のみ`: 語句選択とポップアップ操作を行わない
- 操作表示モード切替:
  - `ポップアップ`: 本文中の語句の近くに操作ポップアップを表示する
  - `下部固定`: 語句選択後に画面下部の固定操作バーだけを表示する
- スマホで本文中の語句をタップする: 語句を選択または選択解除し、複数語句を選択できる
- スマホで語句を選択した状態: 画面下部の固定操作バーから `S/V/O/C/M/clear/save/選択解除` を実行する
- 下部固定モードでは本文上の語句操作ポップアップを表示せず、下部固定操作バーだけを使う
- SVOC/M ボタン: 対象語句の文型ラベルを保存する
- clear ボタン: 対象語句の文型ラベルを削除する
- save ボタン: 対象語句を単語帳保存前の一時 tray に入れる
- 熟語ヒント選択: 対象語句を含む熟語を複数選択できる
- 複数語句を選択中に SVOC/M、clear、save のいずれかを実行した場合は、実行後に選択状態を自動解除する
- tray 内の `×`: 対象語句を tray から外す
- tray の全削除: tray 内の語句をまとめて外す
- 単語帳に保存ボタン: tray 内の語句を単語帳へ保存する
- 戻るボタン: 一覧へ戻る

### スマホ表示優先事項

- 行間を確保して読みやすくする
- 本文幅を広げすぎない
- 下部固定ボタンを置く場合は本文を隠さない
- スマホでは長押しスライド方式を主操作にしない
  - 検討時は「長押し中のポップアップ + 指スライド」を想定していた
  - iOS Safari で長押し時のテキスト選択・コールアウトと競合しやすいため、主操作から外す
  - 初期表示は「タップ選択 + 下部固定操作バー」にする
  - 必要に応じて操作表示モードでポップアップへ切り替えられる

### 文型ラベル・語句保存ポップアップ

- 旧式の単語別セレクトボックス（`未選択` のドロップダウン一覧）は表示しない
- ポップアップは原則として対象語句の下側に表示する
- 下側に表示すると画面から見切れそうな場合だけ、対象語句の上側に表示する
- ポップアップの吹き出し先は対象語句の中央に合わせる。画面端でポップアップ本体がずれた場合も、矢印位置だけを補正して対象語句を指す。
- 下向きポップアップでは、上段に `S`, `V`, `O`, `C`, `M`、その下に `clear`、その下に `save` を置く
- 上向きポップアップでは並びを逆にし、上から `save`、`clear`、`S`, `V`, `O`, `C`, `M` の順に置く
- 文型ラベルの採点は、ポップアップで保存された `english_reader.grammar_answers` を対象にする
- 複数語句が選択されている場合は、ポップアップ内に選択数を表示する
- 熟語ヒントは、対象語句が属する熟語テキストのみを表示し、意味は表示しない
- 熟語ヒントは複数選択できる
- 熟語を選択した状態で `save` を押すと、選択中の熟語をまとめて `type: "idiom"` で tray に追加する
- 熟語語句のハイライトは常時表示しない。熟語構成語へホバーまたはホールドした時だけ表示する

### 単語保存 tray

- tray は reader 画面の本文下に表示する
- reader 画面には tray 状態を示すミニステータスバーを表示する
  - 件数表示（`Tray N件`）を常時表示する
  - 最新追加語句（tray 末尾の語句）を短く表示する
  - `Trayを見る` で本文下の tray 本体へ移動できる
  - tray に語句がある時だけ `保存` を表示し、単語帳保存を実行できる
  - tray が空でも `Tray 0件` を薄く表示して状態を把握できる
- tray に入れた語句は、まだ単語帳には保存しない
- tray 内の各語句の右側に `×` を表示し、押すと tray から削除する
- tray 内に語句がある場合は `全削除` を表示し、押すと tray を空にする
- `単語帳に保存` を押すと tray 内の語句を `english_reader.saved_words` に保存する
- 保存後、保存済みまたは重複をメッセージで示し、保存できた語句は tray から外す

## vocab.html

### 役割

- 保存単語の一覧確認

### 主要UI要素

- 保存単語一覧
- 保存元 passage 表示
- 保存日時
- 削除ボタン
- フォルダ作成フォーム
- フォルダ別フィルタ
- 複数フォルダ所属の切替

### 画面遷移

- passage 参照リンクから `reader.html?id={passage_id}`
- 一覧画面へ戻る導線

### ボタン押下時の挙動

- 単語削除: 対象単語を保存状態から外す
- passage へ移動: 元の本文を開く
- フォルダ作成: 新しいフォルダを追加する
- フォルダ削除: フォルダだけを削除し、所属単語は削除しない
- フォルダチェック変更: 対象単語の `folder_ids` を更新する
- フォルダチェック変更後も、その単語カード内のフォルダ選択パネルは自動で閉じない
- 単語カードの辞書情報セクション見出しは「その他の品詞と意味」ではなく「品詞と意味」を使う
- 単語カードの品詞表示は日本語（名詞 / 動詞 / 形容詞 / 副詞 など）で表示する
- 英文例セクションは開閉できる。開いた時に英文と日本語訳の両方を表示する
- 単語カードの `品詞と意味` `フォルダ` `英文例と日本語訳` は初期表示で展開する

### スマホ表示優先事項

- 1行情報量を絞る
- 削除ボタンの押し間違いを防ぐ

## review.html

### 役割

- 保存単語を暗記シートとして見直す

### 主要UI要素

- 対象選択（全単語 / 任意フォルダ）
- 表示モード切替（英単語を隠す / 意味を隠す）
- フラッシュカード画面への遷移ボタン（`フラッシュカード`）
- 暗記カード一覧
- 答え表示操作
- カードごとの操作案内（「タップして表示」/「タップして隠す」）
- カード上部には語種（単語/熟語）は表示するが、品詞ラベル（例: ARTICLE）は表示しない

### 画面遷移

- passage を開く場合は `reader.html`
- 単語一覧へ移動する場合は `vocab.html`
- フラッシュカード画面へ移動する場合は `flashcard.html`

### ボタン押下時の挙動

- 表示モード切替: 暗記カードで隠す面を切り替える
- フラッシュカードボタン: `flashcard.html` へ移動する
- カード押下: 隠している情報を表示または再度隠す
- カード表示中は操作案内を「タップして隠す」に切り替える
- passage へ移動: 対象本文へ移動する
- 意味表示時は本文内の意味に加えて、品詞ごとの意味一覧も表示する
- 「タップして表示」の案内は1つだけ表示し、重複表示しない
- 品詞ごとの意味一覧は複数品詞がある場合でも全件表示できる
- 品詞表示は日本語（名詞 / 動詞 / 形容詞 / 副詞 など）で表示する
- カードを表示した時は英語例文の下に日本語訳を表示する
- 例文日本語訳が未登録のカードでは和訳を表示しない
- カード表示時は英語例文を表示する
- 品詞ごとの意味一覧をカード内で表示する
- `英単語を隠す` モードでは、英単語を黒塗りマスクで隠す
- `英単語を隠す` モードの非表示時は、タップ操作で英単語を表示する
- 例文欄は英語例文（`example`）と日本語訳（`example_translation_ja`）を併記できる
- `英単語を隠す` モードでは、英単語を隠している間も品詞別の日本語意味を表示する
- 本文中の品詞（`part_of_speech`）がある場合は、その品詞を一覧の先頭に表示する

### スマホ表示優先事項

- 上から順に見直せる単純な縦並びにする
- カードを大きめにし、タップで答えを確認できるようにする

## flashcard.html

### 役割

- 復習用のフラッシュカードを専用画面で操作する
- 単語帳アプリ的な素早い表裏確認の学習感を参考にしつつ、既存アプリをそのまま模倣しない独自のカードUIとして提供する
- 通常の1枚送り学習、横スクロールの一覧確認、大画面の集中モードを切り替えて使えるようにする

### 主要UI要素

- 対象選択（全単語 / 任意フォルダ）
- 初期表示面の選択（英単語先 / 日本語意味先）
- 並び順の選択（通常 / ランダム）
- 大型ポップアップ表示ボタン（`集中モード`）
- 設定直下の大きな1枚表示カード
- 大きな1枚表示カードの下に置く横一列カード一覧
- 現在対象のカード数と現在位置
- 1枚表示時の進行操作（`前へ` / `次へ`）

### 画面遷移

- 復習画面へ戻る場合は `review.html`
- 単語一覧へ移動する場合は `vocab.html`
- passage を開く場合は `reader.html`

### ボタン押下時の挙動

- 対象切替: 表示カードを全単語または指定フォルダへ切り替える
- 初期表示切替: カードの表面を英単語または日本語意味へ切り替える
- 並び替え: 現在対象のカード順をランダムに並び替える
- 通常モードの `前へ` / `次へ`: 設定直下の大きな1枚表示カードを前後へ移動する
- 通常モードのカード下操作は上から `前へ / 次へ`（横並び）、`表裏切替`、`本文へ` の順で配置する
- 横一列カードの押下: 大きな1枚表示カードの対象をそのカードへ移動する
- 集中モードボタン: ブラウザ全画面ではなく大型ポップアップを表示し、1枚表示モードへ切り替える
- カード押下: 表面/裏面を切り替える
- 集中モードの `前へ`: 1つ前のカードへ移動する
- 集中モードの `次へ`: 1つ後のカードへ移動する
- 集中モードの左右キー: 前後のカードへ移動する
- 集中モードの Space / Enter: 表面/裏面を切り替える
- `集中モードを終了`: `前へ` / `次へ` の下に配置し、ポップアップを閉じる
- passage へ移動: 対象本文へ移動する
- 品詞と意味が複数ある場合は縦並びで表示する
- カード内には英単語、品詞別の意味、本文内の意味、英文例、日本語訳を必要に応じて表示する
- 日本語意味先の初期表示では、答えになる英単語を見出しとして表示しない。英文例を表示する場合も対象語句は `____` で伏せる
- 既存アプリの文言、配色、アイコン配置、カード装飾をそのまま使わない

### スマホ表示優先事項

- 設定ボタンは上部で折り返し表示し、タップしやすくする
- カード一覧は横スクロールの1列で連続学習できるようにする
- 集中モードではカード本文と進行ボタンを縦に積み、片手で `前へ` / `次へ` / 表裏切替ができる余白を確保する
