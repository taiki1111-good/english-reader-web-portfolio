# 07_test_plan

## 目的

初期段階では重い自動化より、データ破損防止と基本動作確認を優先する。

## Python スクリプト側の検証

- 入力素材から必要項目を抽出できるか
- `word_count` を算出できるか
- JSON 出力が壊れていないか

## passages.json の妥当性確認

- JSON として読み込めるか
- 各 passage に必須項目があるか
- `id` の重複がないか
- `status` が想定値か

## 必須項目チェック

- `id`
- `title`
- `source`
- `source_url`
- `license_type`
- `word_count`
- `level_hint`
- `tags`
- `text`
- `created_at`
- `status`

## 語数チェック

- 主対象の 100〜200語程度から大きく外れていないか確認する
- 意図的に外れる場合は理由を記録する

## localStorage 保存 / 再読込確認

- 単語保存後、再読込して保持されるか
- 既読状態が再読込後も残るか
- 教材一覧で既読状態を切り替えられるか
- 教材一覧で既読済み、未読、すべてのフィルターが機能するか
- 最後に開いた passage が保持されるか
- 暗記シートの対象フォルダと表示モードを切り替えても保存単語データが壊れないか
- reader のポップアップで付けた S/V/O/C/M ラベルが再読込後も残るか
- 単語フォルダが再読込後も残るか
- 単語の複数フォルダ所属が再読込後も残るか

## 最低限のUI確認

- `index.html` から `reader.html` へ遷移できるか
- `reader.html` で本文が表示されるか
- `reader.html` でセンテンスごとの日本語訳を折りたたみ表示できるか
- PC で語句にカーソルを合わせるとポップアップが出るか
- PC でポップアップの吹き出し先が対象単語を指すか
- PC で語句クリックにより複数語句を一時選択し、S/V/O/C/M、clear、save が選択全体へ適用されるか
- 下側に出すと見切れる位置では、ポップアップが上側に出るか
- スマホ幅では語句長押し中にポップアップが出て、指をボタンへ滑らせて離すと操作できるか
- 熟語に含まれる単語が色付きになり、PC hover / スマホ hold で熟語ヒントが出るか
- センテンス単位の背景色が表示されないか
- save で tray に入り、`×` で tray から削除できるか
- tray の `全削除` で tray が空になるか
- `単語帳に保存` で tray 内の語句が `vocab.html` に表示されるか
- `vocab.html` で保存単語が表示されるか
- `vocab.html` でフォルダ作成、削除、複数所属、フォルダ別絞り込みができるか
- `review.html` で全単語または任意フォルダを暗記シート化できるか
- `review.html` で英単語隠しと意味隠しを切り替えられるか
- `review.html` の `フラッシュカード` ボタンから `flashcard.html` へ遷移できるか
- `flashcard.html` で全単語または任意フォルダを対象にできるか
- `flashcard.html` で初期表示面（英単語先 / 日本語先）を切り替えられるか
- `flashcard.html` の日本語先初期表示で、答えの英単語と英文例内の対象語が見えていないか
- `flashcard.html` でランダム並び替えを実行すると表示順が変わるか
- `flashcard.html` で複数品詞・複数意味が縦並びで表示されるか
- `flashcard.html` で対象以外の設定項目（初期表示 / 並び順）も選択UIで切り替えられるか
- `flashcard.html` で設定の直下に大きな1枚表示カードが表示されるか
- `flashcard.html` で大きな1枚表示カードの下に横一列カード一覧が表示されるか
- `flashcard.html` の通常モードで `前へ` / `次へ` によって1枚ずつ移動できるか
- `flashcard.html` の横一列カード押下で大きな1枚表示カードへ反映されるか
- `flashcard.html` の通常カードが既存アプリの完全な模倣ではなく、repo 独自の配色・配置・文言になっているか
- `flashcard.html` で集中モードボタン押下時に大型ポップアップが表示されるか
- `flashcard.html` の大型ポップアップで1枚表示を順番に見れるか
- `flashcard.html` の大型ポップアップで `前へ` / `次へ` によって前後移動できるか
- `flashcard.html` の大型ポップアップで左右キーによる前後移動、Space / Enter による表裏切替ができるか
- `flashcard.html` の大型ポップアップで `集中モードを終了` が `前へ` / `次へ` の下に表示されるか
- スマホ幅でも操作不能にならないか
