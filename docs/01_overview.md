# 01_overview

## このプロジェクトが目指すもの

再利用可能な英語長文を使い、読む、記録する、単語を残す、あとで見直す、という最小学習サイクルを回せる軽量Web教材を作る。  
初期段階では高機能化よりも、素材と学習状態を手元で扱える小さな完成形を優先する。

## なぜ最初はアプリではなく Web なのか

- 初期実装が軽い
- 配布と確認が簡単
- 依存技術を増やしすぎない
- localStorage で最低限の学習状態を保持できる
- 将来 `PWA` や `IndexedDB` に拡張しやすい

## なぜ既存の再利用可能英文を使うのか

- まずは教材UIの成立を優先したい
- 自作文章や生成依存に寄らず継続できる
- 出典とライセンスを記録しやすい
- 素材追加の運用を標準化しやすい

## 今はやらないこと

- ネイティブアプリ化
- React / Flutter 導入
- 認証
- 課金
- クラウド同期
- 外部生成API前提の機能
- 曖昧な利用条件の素材収集

## 初期成立イメージ

- 少数の長文データを `passages.json` として保持する
- `reader.html` で本文を表示する
- 保存した単語を `localStorage` に記録する
- `vocab.html` と `review.html` で確認できる
- 読了や既読状態をローカルで保持する
